# Baidu Custom Style

Standalone Less.js stylesheet for Baidu single-column search pages.

## Usage

Enable the Baidu custom stylesheet option in the userscript settings, then use this Raw URL as the stylesheet link:

`https://raw.githubusercontent.com/lingling225/baidu-custom-style/main/baidu-single-column.less`

The stylesheet is independent from `langren1353/GM_script` and is intended to be loaded through the userscript's Less.js custom-style support.
