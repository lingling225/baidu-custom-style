# Baidu Custom Style

Standalone Less.js stylesheets for Baidu and Google single-column search pages.

## Usage

Enable the corresponding site custom stylesheet option in the userscript settings, then use one of these Raw URLs:

`https://raw.githubusercontent.com/lingling225/baidu-custom-style/main/baidu-single-column.less`

- Google: `https://raw.githubusercontent.com/lingling225/baidu-custom-style/main/google-single-column.less`

The stylesheets are independent from `langren1353/GM_script` and are intended to be loaded through the userscript's Less.js custom-style support.
